# ⚡ QuizPulse – Interactive Online Quiz Application

> **Web Technology Project**  
> *Developed by Faraz Hussain*

QuizPulse is a dynamic, high-performance, single-page web application designed for real-time academic testing, interactive knowledge evaluation, and instant score tracking. Built with pure **HTML5, CSS3, and JavaScript (ES6)**, it offers a seamless quiz-taking experience complete with per-question countdown timers, real-time score analytics, detailed answer breakdown reviews, and an admin question management module.

---

## ✨ Key Features

- **⏱️ Live Interactive Quiz Engine:** Real-time countdown timer per question, dynamic question navigation, and live progress indicators.
- **📊 Instant Score & Performance Tracking:** Automated percentage calculation, accuracy metrics, and instant visual scorecards upon quiz completion.
- **🔍 Comprehensive Review Mode:** Per-question post-quiz analysis highlighting correct answers versus user selections with explanation badges.
- **➕ Admin Question Manager:** Interactive Modal form allowing instructors to dynamically add custom questions across various academic subjects (CS, Web Tech, AI, General Knowledge).
- **🎨 Sleek Dark & Vibrant Theme:** Modern UI styled with Electric Violet, Cyan, Emerald, and Amber color palettes.
- **⚙️ Profile & System Settings:** Customizable user profile settings managed under system admin **Faraz Hussain**.

---

## 🛠️ Tech Stack

- **HTML5:** Dynamic form components, semantic structures, and accessible layouts.
- **CSS3:** Flexbox, CSS Grid layout, animated timer bars, CSS Variables, and custom modal styling.
- **JavaScript (ES6):** State management, setInterval countdown timers, dynamic array manipulation, and dynamic DOM rendering.
- **FontAwesome v6:** Comprehensive educational, timer, and UI icons.
